# Project Instructions

This is a small personal knowledge-feed project.

Priorities:
1. Keep the system free to operate.
2. Keep the architecture simple and preserve static GitHub Pages deployment.
3. Never commit secrets; treat LLM output as untrusted input.
4. Prefer deterministic Python code and human-readable Markdown.
5. Keep prompts in `src/knowledge_feed/prompts.py`.
6. Do not introduce paid APIs or unnecessary infrastructure.
7. Do not modify published articles unless explicitly requested.
8. Run tests before completing changes.
